# T3KOT — исправление сенсорного управления

## Что изменено
- Джойстик и обзор используют независимые пальцы.
- Удалена генерация искусственных событий мыши для сенсорного обзора. Камера поворачивается только через `apply_touch_look()` для пальца, начавшего движение в правой зоне экрана.
- Позиция кнопки прыжка рассчитывается относительно фактического размера экрана.
- Сохранено существующее управление; управление не добавлялось второй раз.
- Исправлена логика двойного прыжка в `Player.gd`: один дополнительный прыжок в воздухе, сброс после приземления.

## Проверка
Открой `project.godot` в Godot 4.7 и запусти `scenes/Main.tscn`. На телефоне проверь:
1. удерживать джойстик и убедиться, что камера не вращается;
2. одновременно вести джойстик и свайпать правой рукой;
3. нажать прыжок дважды в воздухе;
4. проверить интерфейс в портретном и альбомном разрешении.

Архив содержит исходники, не готовый APK. Перед установкой на телефон сделай Android Export из Godot. Я не могу подтвердить запуск на физическом устройстве из этой среды.
